# Cai dat Trimui Terminal v0.1.0

Terminal + BT survey cho TrimUI Brick Pro (Stock OS) va Smart Pro S.

## 1. Tai dung goi

1. Mo trang Releases cua repo nay.
2. Tai `trimui-terminal-v0.1.0.zip` (khong tai Source code).
3. Co the doi chieu SHA-256 bang file `.zip.sha256` di kem.

## 2. Cai moi

1. Giai nen ZIP vao goc the nho.
2. Kiem tra duong dan cuoi la `Apps/TrimuiTerminal/launch.sh`.
3. Lap the vao may, mo **Trimui Terminal**.

## 3. Chay BT survey

1. Trong terminal go: `sh bt-survey.sh`
2. File `Bt-survey-*.log` nam canh `launch.sh`.
3. Copy file log ra may tinh de gui danh gia Bluetooth.

## 4. Dieu khien

- D-pad: chon phim tren ban phim ao.
- A: go phim. B: backspace (gui Ctrl+C khi an help).
- L1: shift. R1: giu phim. X: an/hien ban phim. Y: doi vi tri ban phim.
- START: enter. SELECT: tab. MENU: thoat.
- L2/R2: cuon len/xuong khi tat ban phim.
